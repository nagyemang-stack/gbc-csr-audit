# Methodology — GBC CSR Communications Audit

## Question
How can publicly available institutional and partnership information be organised into a stakeholder map and a transparent CSR communications audit for GBC?

## Data boundary
This is portfolio analysis, not a GBC report or commissioned client work. It uses the public materials named in the README, including the 2024 Stakeholders Conference, institutional reports, public media analysis, consultation material, and partnership announcements. Private organisational records are excluded.

## Approach
I mapped eight stakeholder groups using influence and communication need scores, then assessed CSR communication across six dimensions against an explicit best-practice benchmark. The scores are analytical judgements built from the cited public material; they are not official GBC performance ratings.

## Outputs
`output/gbc_stakeholder_matrix.png`, `output/gbc_csr_radar.png`, `output/gbc_csr_gap_analysis.png`, and `output/gbc_executive_summary.json` are generated by `scripts/analyze_gbc_csr.py`.

## Reproduction
```bash
pip install -r requirements.txt
python scripts/analyze_gbc_csr.py
```

## Interpretation and limitations
The stakeholder and CSR scores support prioritisation questions, not an independent audit opinion. Public-source coverage may be incomplete, benchmark selection affects the gap size, and partnership announcements do not prove total organisational CSR activity.
